# FitTrack v1

PHP + MySQL + HTML + Tailwind + Vanilla JS + PWA.

## Uruchomienie

1. Zaimportuj `database/schema.sql` do MySQL.
2. Ustaw dane bazy w `config/config.php`.
3. W katalogu projektu uruchom:
   `php -S localhost:8000`
4. Otwórz:
   `http://localhost:8000`

Test API:
`http://localhost:8000/api/health`

To jest fundament pierwszej wersji. Następny etap to pełny kalendarz, kreator treningów, aktywny trening, timery, historia i progres.
